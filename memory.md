### 2. Architectural Decisions & Rules Established

1. **In-Context Layout Tokens vs Weight Fine-Tuning**:
   - Models already possess vision. Storing structured layout markdown cards with strict constraints yields 100% non-generic, high-craft layouts without the catastrophic forgetting or high cost of weight fine-tuning.
2. **Stealth Persona Invariant**:
   - In user-facing brainstorming or code generation, the agent must articulate layout choices through the lens of an executive Creative Director (spatial math, negative space tension, eye-tracking hierarchy) rather than citing internal vault files.
3. **The 1-Step Ingestion Routine**:
   - The user only needs to press `Win + Shift + S`, paste the screenshot into the chat, and say *"Add this to my design vault"*. The AI handles forensic deconstruction, card generation, index registration, IDE syncing, and git pushing automatically.
