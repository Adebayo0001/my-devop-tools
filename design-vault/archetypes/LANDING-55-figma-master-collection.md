## Key Invariants Across All 55 Layouts (Never Change)

1. **Anti-Centered Generic Slop Floor**:  
   Not a single one of these 55 layouts uses the lazy "centered text with 3 generic cards below". Every single layout uses asymmetric split grids, staggered bento cards, floating hardware renders, or architectural archways.
2. **375px Mobile Viewport Physics**:  
   - All multi-column splits un-stick and stack vertically without lateral clipping.
   - All containers enforce `max-w-full overflow-x-hidden px-4 sm:px-6`.
   - All interactive touch targets (buttons, pills, tabs) maintain `>= 44×44px`.
3. **Typography Role Discipline**:  
   - High-contrast display face for H1 headlines (e.g. Syne, Instrument Serif, Clash Display, Space Grotesk).
   - High-legibility sans-serif for body (Plus Jakarta Sans, Inter, Satoshi, Geist).
   - Monospace uppercase for index indicators (`01 / 02 / 03`).
